## TeamCode Module

This is the module where all of the team's code goes, forked from the team's repo. My pathing code is in [Motion](./Motion) subdirectory. The most interesting files are [Motion/Controllers/MPC.java](./Motion/Controllers/MPC.java) and [Motion/Controllers/MPCPath.java](./Motion/Controllers/MPCPath.java).

For example usage, look at [AAAOpModes/Autonomous/RedFrontAuto.java](./AAAOpModes/Autonomous/RedFrontAuto.java) (an example autonomous with this pathing system) and [AAAOpModes/Testing/MPCTest](./AAAOpModes/Testing/MPCTest.java) (a testing/tuning class for individual paths).
